# منِ مجازی — محمد جواد محمودی

نسخه اولیه وب‌سایت شخصی و تخصصی محمد جواد محمودی.

## اجرا
فایل `index.html` را با مرورگر باز کنید. برای تجربه بهتر می‌توانید پروژه را با یک Live Server اجرا کنید.

## ساختار
- `index.html` ساختار صفحه
- `style.css` طراحی و واکنش‌گرایی
- `script.js` محتوای کارت‌ها و تعاملات
- `assets/images/` محل تصاویر سایت

## نکته
تصویر پس‌زمینه فعلاً به صورت placeholder تعریف شده و می‌توانید تصویر شخصی/کاری مناسب خودتان را در مسیر `assets/images/hero-placeholder.jpg` قرار دهید.
